# 火柴人刷图 v0.5：夜雾水墨风

本稿是对 v0.4 的画面改版，只写画面相关的部分。关卡结构、技能数值、评分、复活规则不变。

## 1. 风格参考

- 角色：纯黑剪影，参考《忍者必须死》的墨色角色（截图参考：黑衣忍者 + 红色墨线弧光）。
- 场景：夜间青蓝色雾气，前后几层山石和树的剪影，远处用雾淡化。参考截图是林间红叶的夜景。
- 颜色：冷色为主（青、蓝、黑），只有红色做点缀：披风、枫叶、技能弧线。

## 2. 火柴人

| 部位 | 做法 |
| --- | --- |
| 身体 | 纯黑。四肢用锥形圆柱，关节处粗、末端细，比原来的均匀细线更有笔锋感。 |
| 轮廓 | 不做复杂的描边。用一个略大的背面模型加淡青色，做出边缘的光晕，成本低。 |
| 头 | 小圆点，不再是圆环。各角色用不同的头饰区分。 |
| 披风 | 红色长飘带，由 12 段组成。跑动时向身后拖，站立时轻轻飘。 |

## 3. 角色和武器（重做外形，玩法不变）

每个角色保留原来的武器类型、属性和技能，只改外观。

| 角色 | 武器（重做后） | 头饰 | 外形特点 |
| --- | --- | --- | --- |
| 剑客 | 黑刃长剑，刃口带一道白光，护手是红色短线 | 红色头巾 | 站得直，动作利落 |
| 枪客 | 黑杆长枪，枪尖一缕红缨 | 无 | 身形更高，披风最长 |
| 拳师 | 黑色拳套，指节处缠红布 | 光头（无头饰） | 体型最厚 |
| 暗器师 | 两把短刃，刃身很细 | 面罩（只露眼睛） | 最小最轻 |
| 扇舞者 | 黑色折扇，展开时扇面上一道红墨 | 发髻 | 身形最纤细 |

## 4. 场景（可以选择）

玩家在开局时选一个场景，整局使用同一套配色。选项：

| 场景 | 配色 | 说明 |
| --- | --- | --- |
| 红枫夜雾（默认） | 青蓝雾，红色枫叶树冠 | 参考截图 |
| 月下竹海 | 深蓝雾，月色偏白，竹林剪影 | 更安静 |
| 血月古寺 | 暗紫雾，血红色的月 | 更压抑 |

五个房间沿用原来的结构，只换配色和树木。

## 5. 技能特效

本轮不重做技能特效，只做两点：红色墨线弧光用于剑光拖尾和披风，技能的颜色和色调跟随所选场景。

## 6. 性能原则

- 场景的装饰尽量用 InstancedMesh。
- 不做全屏着色器。轮廓只用背面模型，不做后处理描边。
- 披风只改 12 段顶点的位置，不新建几何体。
