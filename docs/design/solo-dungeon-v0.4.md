# 火柴人刷图 改版设计 v0.4

本稿是对 `solo-dungeon.md`（v0.3）的增补，只写有改动的部分。没提到的沿用 v0.3，比如 2.5D 玩法、房间三选一、评分、复活规则。

## 2. 火柴人和剑变细

现在的参数偏粗，加上描边和辉光后看起来像一团白。改动如下：

| 部位 | 现在 | 改后 |
| --- | --- | --- |
| 四肢半径 | 0.075 | 0.045 |
| 躯干半径 | 0.094 | 0.06 |
| 头 | 半径 0.19 | 半径 0.13 |
| 描边放大倍数 | 1.45 倍 | 1.2 倍，只在主角身上保留 |
| 剑身宽度 | 0.06 | 0.03 |
| 剑身厚度 | 0.025 | 0.012 |
| 剑格 | 宽 0.26 | 宽 0.14，加金色细线 |
| 辉光强度 | 剑身 2.4 | 剑身 1.6，剑尖加一个小亮点 |

另外，身体颜色改成墨色和月白两色。主角是月白色，敌人是墨色加一条角色色的细边，这样远处也能分清敌我。

## 3. 角色

### 3.1 五个角色

每个角色有自己的武器、属性和技能，技能不共用。开局先选角色，之后房间三选一的技能卡只从本角色的技能池里抽。

| 角色 | 武器 | 定位 | 基础属性 | 特点 |
| --- | --- | --- | --- | --- |
| 剑客（现有） | 长剑 | 均衡近战 | HP 1200，攻击 100 | 现有 8 个技能保留 |
| 枪客 | 长枪 | 远距离突刺 | HP 1100，攻击 95 | 攻击距离远，能隔着敌人打，枪尖拖出青龙虚影 |
| 拳师 | 拳套 | 近身爆发 | HP 1400，攻击 115，速度慢 | 连击多、蓄力重拳，可以硬扛伤害 |
| 暗器师 | 飞刀、暗器 | 远程控场 | HP 900，攻击 90 | 远程输出，有闪避和隐身，血最少 |
| 扇舞者 | 折扇 | 中距离，控制 | HP 1000，攻击 95 | 扇子能飞出去回旋，还能拉人、放风暴 |

暗器师和扇舞者的远程攻击不靠子弹，只靠飞刀、扇叶这类可以在屏幕上看见的实体飞行物，和现在的剑气一样走逻辑坐标判定。

### 3.2 各角色的技能（每人 4 个技能 + 1 个觉醒技）

**枪客**
- 龙出水：直线突刺，穿透路径上所有敌人，尾迹化成一条青龙虚影。
- 回马枪：后撤一步并反刺。闪避结束后 1 秒内放技能会自动接这一招。
- 横扫千军：以自己为中心的圆形扫击，把敌人击飞。
- 梅花三弄：三连快刺，每刺一下落一朵红梅形的特效。
- 觉醒「龙啸九天」：一条巨大的青龙从屏幕一侧游过，沿途所有敌人被咬中，最后枪尖刺穿画面中心。

**拳师**
- 崩山拳：蓄力 0.8 秒的重拳，放出一圈地面冲击波，沿地面推开敌人。
- 连环崩拳：普攻的变体，第三拳会带出拳影残像。
- 旋风腿：圆形回旋踢，可以打到身后的敌人。
- 震地拳：击落地面，周围敌人被震浮空，地面出现裂纹。
- 金钟罩：4 秒金色护体，期间受伤减半，冷却最长。
- 觉醒「罗汉伏魔」：金身佛影在身后出现，拳头落下时震屏，敌人全部倒地。

**暗器师**
- 飞刀：一把飞刀直线飞出，命中时炸出一小团火花。
- 天女散花：扇形抛出 7 枚暗器，每枚击中后留一道细线。
- 暗影步：短暂隐身后瞬移到最近敌人身后，隐身期间攻击伤害翻倍。
- 毒蒺藜：在脚下撒一片毒蒺藜，敌人踩上后减速并持续掉血。
- 觉醒「千机暗雨」：满屏暗器从天上落下，画面一片银色，落点位置留下毒雾。

**扇舞者**
- 飞花扇：折扇飞出去旋转一圈再飞回手中，途中化成一圈花瓣刃。
- 水袖卷：扇面一挥，把远处的敌人拉到身边。
- 墨扇风暴：扇面展开成一片墨色旋风，持续数秒，墨点飞散后留下水墨痕迹。
- 雷扇 / 火扇：和元素组合，扇子带上雷或火的属性，见 5.3。
- 觉醒「满月风华」：扇子展开成一轮满月，满屏花瓣和墨点，敌人被月光打中后停住。

### 3.3 武器与模型

- 武器模型都是程序生成的细线条，没有外部素材。
- 枪、拳套、飞刀、扇子各有一个模型，共用 `stickmanRig.ts` 的武器接口。
- 扇子在手上是折起的，展开时才变成扇面，在原地播一段展开动画。

## 4. 场景：古风中国风

### 4.1 整体风格

- 配色：墨黑、朱红、青灰、鹅黄、月白。去掉暖褐色岩石。
- 光源：月光做主光（冷色平行光），灯笼和烛火做点光源（暖色）。
- 雾：夜色中的薄雾，远处的景色逐渐淡掉。
- 远景：用 canvas 画的水墨山水剪影，做成几层面片，越远越淡。

### 4.2 地图与房间

地图名改为「古寺夜战」，五个房间：

| 房间 | 环境 | 敌人 |
| --- | --- | --- |
| 1 山门 | 石阶、朱红门楼、两侧石灯笼 | 山贼刀手 |
| 2 竹林 | 竹子（细圆柱）、风吹竹叶的粒子、月光透过竹叶 | 山贼弓手、藤牌兵 |
| 3 古寺庭院 | 石灯、香炉冒烟、飘动的经幡 | 山贼刀手、藤牌兵 |
| 4 藏经楼 | 木柱、书架、烛台、飘落的纸页 | 火药傀儡（自爆）、山贼弓手 |
| 5 血煞大殿（Boss） | 红色帷幔、佛像剪影、大殿中央的血池 | Boss：血煞堂主 |

### 4.3 环境细节

- 落花和竹叶：用 `InstancedMesh` 做，同屏最多 150 片，画质低时减半。
- 烛火和灯笼：用加法混合的小面片做光晕，晃动的节奏错开，看起来不呆板。
- 水墨痕迹：技能结束后在地上留下墨点，最多保留 10 秒，超过就淡出。

## 5. 技能华丽化

### 5.1 视觉规范

每个技能分三个阶段，每段都要有可见的变化：

1. 起手（0.1 到 0.3 秒）：脚下或手上出现符纸、气旋或光圈，角色身上带一层元素色。
2. 主体：主要特效，有拖尾、粒子、残影或飞行物。大招还要有屏幕色调变化。
3. 收尾：命中爆点加飘落的花瓣或火花，屏幕边缘轻微闪色。

中国风元素优先用这几样：花瓣、墨点、符纸、剑气化龙、灯笼的光晕、朱红和金色的光线。

### 5.2 示例

| 技能 | 华丽的地方 |
| --- | --- |
| 剑客·一剑霜寒 | 拔剑时地面结出一圈冰纹，剑光化成一条白龙冲出去，途中撒下冰晶 |
| 枪客·龙出水 | 枪尖拖出一条青色虚影龙，龙身穿过所有敌人，结束时龙头在屏幕边缘回望 |
| 扇舞者·飞花扇 | 扇子飞出时带起一圈花瓣，回旋时每一圈都是一道花瓣刃 |
| 扇舞者·墨扇风暴 | 墨色旋风，墨点飞散后在地上留下水墨花纹，持续数秒 |
| 暗器师·天女散花 | 七枚暗器在空中划出弧线，落地时每一枚炸出一朵小花 |
| 拳师·崩山拳 | 蓄力时身后出现山影，出拳时山影压下，屏幕震动，地面裂开 |

### 5.3 元素组合的视觉

- 蒸汽爆炸：白色雾气翻滚，中间浮现大大的「蒸汽爆炸」字样，字体用书法风格。
- 过载：紫色雷光炸开，字样用朱红色。
- 碎冰：冰面碎成玻璃状的碎片，飞得满屏都是。

### 5.4 大招的运镜

大招保留 v0.3 的重档运镜，每个觉醒技再加一个画面效果：

- 龙啸九天：屏幕一侧出现青龙，画面色调变青。
- 罗汉伏魔：画面变金色，佛影背后出现。
- 千机暗雨：画面变银灰，雨点从上落下。
- 满月风华：画面变成月白，满屏花瓣。

### 5.5 性能

- 花瓣、墨点、暗器都用 `InstancedMesh`，避免每帧创建对象。
- 水墨风暴的墨点用 canvas 生成的贴图，不做全屏 shader。全屏 shader 在中低端手机上太慢。
- 帧率掉到 45 以下时，花瓣数量减半，关掉墨点的拖尾。

## 7. 技术影响

- 角色数据放在 `stickmanData.ts`，每个角色一份配置。
- 技能逻辑现在全部在 `stickmanScene.ts`，已经超过 2000 行。加了 5 个角色后应拆分，建议每个角色一个文件，放在 `apps/web/src/solo/stickmanRoles/`。
- 火柴人模型按武器类型生成，新增 `spear`、`fist`、`dagger`、`fan` 四种武器。
- 美术参数集中在一处，改版时不用到处找数字。
- 工作量较大，建议分两步做，见第 8 节。
