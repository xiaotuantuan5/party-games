# ⚔️ 火柴人刷图 设计稿 v0.3

单人横版动作闯关，参考《地下城与勇士》的刷图体验：一张地图分成若干房间，清完一间开下一间的门，最后打 Boss，结算评分。
本稿只定玩法和范围，不涉及开发排期。标注 **[MVP]** 的是第一版必须有的，其余放到后续版本。

**已确认：**
- 名字叫「火柴人刷图」，只做横屏，主角是火柴人。
- 第一版 8 个普通技能 + 1 个觉醒技。
- 只做单局，不做局外解锁和存档（只存最高分）。
- v0.3 改动：画面从 2D 精灵图改为 **3D 火柴人**，平时是 DNF 式的固定斜视角，放大招时切到 3D 运镜（见第 3 节）。

## 1. 一句话定位

横屏刷图，一局 3~5 分钟。主角是一个火柴人，有十几个光效夸张的技能，可以互相取消、接成连招。房间里满屏都是伤害数字，打完给一个 SSS~D 的评分。

- 放在首页「一个人玩」分页，和 🚀 星际穿梭 并列，纯前端运行，不经过服务端。
- 音效、震动用 `sound.ts` 的 `sfx` / `vibrate`，最高分用 `soloGames.ts` 的 `saveBest`。

## 3. 画面

### 3.1 为什么从 2D 精灵图改成 3D

你提了两个方向：整体做成 3D，或者只在放技能时切 3D 视角。比较如下：

| 方案 | 优点 | 问题 |
| --- | --- | --- |
| A. 全 3D 火柴人，平时固定斜视角，大招时运镜 | 火柴人就是几根圆柱加一个球，3D 模型很便宜，不需要素材；相机可以随便转；光效、拖尾、bloom 都更好做 | 动作要做 3D 姿势，比 2D 多调一个轴 |
| B. 2D 精灵图，放技能时切 3D 视角 | 平时画面更像 DNF | 精灵图是纸片，相机一转就露馅，为了运镜还得再做一套 3D 模型，等于做两遍 |

**选 A。** 火柴人用 3D 来做反而最省事。平时的相机固定成 DNF 那样的斜视角，玩起来和 2.5D 横版一样；大招时相机才离开固定位置转起来。
战斗判定和 v0.2 一样，仍然是 2.5D 的逻辑坐标，3D 只影响画面。

### 3.2 视角
- **玩法仍然是 2.5D 横版**：角色可以左右走、上下走（纵深方向），攻击只打到纵深相近的敌人。
- 逻辑坐标：`x` 横向、`z` 纵深（房间约 30 × 6 单位），跳跃和浮空用 `y`，直接对应 3D 场景的坐标轴。判定只在逻辑坐标里做。
- **平时相机**：透视相机，视野较窄（约 30°），从侧前上方约 25° 俯视，看起来接近 DNF 的横版画面。相机跟随主角横向移动，房间两端锁住。
- **技能运镜**：见 3.4。

### 3.3 3D 火柴人（不需要美术素材）
- 模型全部用代码生成：球形的头，圆柱的躯干、上臂、前臂、大腿、小腿，用关节层级连起来（简单骨骼）。
- 动画：在 `stickmanRig.ts` 里为每个动作写几个关键姿势（每个关节的旋转角度），播放时在关键帧之间插值。普攻、技能、受击、倒地、死亡都用这套数据。
- 主角：白色发光身体，带黑色描边（反向法线描边），手里一把发光的剑，剑挥动时拖出光带（ribbon trail）。技能发动时身体换成对应元素的颜色（火红、冰蓝、雷紫）。
- 敌人：同样是火柴人，用颜色和简单几何道具区分，比如绿色哥布林戴锥形尖帽，盾兵举方盾，弓箭手背箭袋。Boss 体型放大 2.5 倍，加披风和王冠。
- 死亡：火柴人的每根肢体变成独立的小物体，被打飞后散落在地上，然后淡出。
- 场景：洞窟地面、两侧岩壁、石柱、木箱都用低多边形几何体，远景用剪影面片，风格和火柴人统一。

### 3.4 技能运镜

运镜会打断操作，用多了会晕、会烦，所以分三档：

| 档位 | 用在哪里 | 相机怎么动 | 时长 | 玩家能否操作 |
| --- | --- | --- | --- | --- |
| 轻 | 所有普通技能 | 不离开平时视角，只做轻微推近、倾斜、震屏 | 0.2~0.4 秒 | 能 |
| 中 | 雷霆落、冰霜领域、精英怪 / 房间最后一个怪被击杀 | 相机下沉到侧面低角度，时间放慢到 0.3 倍，然后回到平时视角 | 约 0.8 秒 | 不能，期间主角无敌 |
| 重 | 觉醒技、Boss 登场、Boss 被击杀 | 完整 3D 运镜，见下方示例 | 1.5~2.5 秒 | 不能，期间时间暂停、主角无敌 |

**万剑归宗的运镜示例 [MVP]：**
1. 画面变暗，相机快速推到主角正面特写，主角举剑（0.4 秒）。
2. 相机绕到主角背后往上拉，看到 100 把光剑在主角身后排成扇形（0.6 秒）。
3. 相机切回平时视角，光剑依次射向全屏敌人，这一段恢复正常速度（1 秒）。
4. 相机抬到高处俯视，一把巨剑从天上劈下，全屏白闪 + 强震屏（0.5 秒）。

**规则：**
- 中、重档运镜期间，敌人的计时也暂停，保证玩家不会因为看动画而挨打。
- 点屏幕任意位置可以跳过运镜，直接看结果。
- 暂停菜单里可以把运镜关掉（只保留轻档）。
- 同一档的中档运镜 3 秒内最多触发一次，避免连续卡顿。
- 运镜结束后，相机用 0.2 秒平滑回到平时位置，不直接跳回。

### 3.5 渲染方式
- 用 `three` 渲染，复用星际穿梭的辉光后期（bloom）。
- 剑光、剑气、爆炸等特效用加法混合（additive），叠在一起会越来越亮。
- 阴影：只给火柴人和大物件画一个脚下的圆形假阴影，不开实时阴影，节省性能。

### 3.6 横屏
- 只支持横屏。竖屏打开时盖一层「请把手机横过来」的提示，并暂停游戏。
- 点「开始」时请求全屏，并尝试 `screen.orientation.lock("landscape")`。安卓 Chrome 支持；iOS Safari 不支持锁定，只能靠提示。
- 画面按 16:9 设计，更宽的屏幕两边多露一点场景，不拉伸。

## 4. 操作

横屏下左手管移动，右手管攻击和技能。

```
┌───────────────────────────────────────────────────────────┐
│ HP ████████  MP █████   连击 32        小地图   ⏸         │
│                                                           │
│                                                           │
│                                          [技4] [技5] [技6] │
│    ( 摇杆 )                         [技1] [技2] [技3]      │
│                              [闪避]  [跳]   ( 攻击 )  [觉醒]│
└───────────────────────────────────────────────────────────┘
```

| 操作 | 手机 | 键盘 |
| --- | --- | --- |
| 移动（8 方向） | 左下虚拟摇杆（按在哪里摇杆就出现在哪里） | 方向键 / WASD |
| 普通攻击 | 右下大按钮，连点出连招 | J |
| 跳跃 | 按钮 | K |
| 闪避（短无敌） | 按钮 | L / Shift |
| 技能 1~6 | 攻击键上方两排，带冷却转圈 | U I O / Y H N |
| 觉醒 | 能量满时按钮发光 | Space |

- **[MVP]** 输入缓冲：动作后段 0.15 秒内按下的键会排队执行。
- **[MVP]** 技能取消：普攻和大部分技能的后摇可以被另一个技能打断（见 5.4），这是连招的基础。
- **方向技能**：部分技能按住时可以用摇杆改方向（比如月牙斩往上下斜着放）。
- 技能键上显示冷却、MP 不足的灰态，可用时有一圈微光。

## 5. 战斗系统

### 5.1 手感（最重要）
- **[MVP]** 打击停顿（hit stop）：命中时双方冻结 50~80ms，重击更长。
- **[MVP]** 受击反馈：敌人闪白、后退、飘伤害数字，暴击数字更大更黄。
- **[MVP]** 屏幕震动：重击、Boss 落地、爆炸时轻震；手机同时短震动。
- **[MVP]** 浮空与追击：部分招式把敌人挑起来，空中的敌人还能被继续打；落地后有短暂倒地，倒地时伤害减半，防止无限连。
- 霸体：Boss 和精英怪出招时不会被打断，身上有金色描边提示。

### 5.2 数值
- 主角：HP、MP、攻击、暴击率。MP 随时间回复，普攻命中也回少量 MP。
- 伤害 = 技能倍率 × 攻击 × (0.9~1.1 随机) × 暴击(1.5)。
- 连击数：2 秒内持续命中就累加，显示在右上角，影响结算评分和觉醒充能速度。

### 5.3 元素状态
技能分成 4 种元素。状态叠在一起会触发额外效果，鼓励换着技能打：

| 元素 | 状态 | 效果 | 组合 |
| --- | --- | --- | --- |
| 🔥 火 | 灼烧 | 每秒掉血，3 秒 | 灼烧 + 冰冻 → **蒸汽爆炸**，范围伤害 |
| ❄️ 冰 | 冰冻 | 定住 1.5 秒，Boss 改为减速 | 冰冻时被重击 → **碎冰**，伤害 ×2 |
| ⚡ 雷 | 感电 | 每次被打会电到旁边 1 个敌人 | 感电 + 灼烧 → **过载**，原地雷爆 |
| 🌑 暗 | 标记 | 下次受到的伤害 +30% | 标记的敌人死亡 → 掉落 MP 球 |

组合触发时屏幕中间闪一个大字（「蒸汽爆炸！」），并给额外分数。

### 5.4 连招规则
- 普攻 → 任意技能：可以取消。
- 技能 → 另一个技能：后摇阶段可以取消，同一个技能不能取消自己。
- 任意动作 → 闪避：随时可以取消，但闪避有 1 秒冷却。
- 空中可以放标注「空中可用」的技能，落地前最多放 2 个。
- 例：普攻 ×2 → 升龙斩（挑起）→ 空中跳起 → 空中连舞 → 雷霆落（砸地）→ 落地接旋风斩。

### 5.5 火柴人的技能

主角只有一个职业，但技能很多：**共 14 个普通技能 + 3 个觉醒技**。
一局开始带 3 个技能，每清完一个房间可以学新技能或强化已有技能（见第 8 节），技能栏最多装 6 个，所以每局的技能组合都不一样。

#### 觉醒技（靠击杀和连击充能，每局约 2~3 次）

开局三选一，整局固定。发动时时间暂停，走「重」档 3D 运镜（见 3.4），运镜里放出大招。

| 觉醒技 | 效果 | 视觉 |
| --- | --- | --- |
| **万剑归宗** **[MVP]** | 背后展开 100 把光剑，依次射向全屏敌人，最后合成一把巨剑劈下 | 光剑排成扇形悬在身后，射出时满屏光轨，巨剑落下时全屏白闪 + 强震屏 |
| **天雷灭世** | 全屏连续落下 12 道雷，所有敌人感电并倒地 | 天空变成紫色，闪电把整个房间照亮 |
| **火柴人暴走** | 8 秒内变成金色，所有技能没有冷却、不耗 MP，移动和攻击速度 +50% | 身体发金光，每一步都留下金色残影，背景加速度线 |

#### 技能强化
每个技能可以强化 2 次，每次三选一一个方向，例如：
- 月牙斩：「一次放 3 道」/「剑气变大 2 倍」/「命中后爆炸」
- 疾风突刺：「可以连续冲 2 次」/「终点放冰霜领域」/「路径留下火焰」
- 旋风斩：「持续时间 ×2」/「结束时甩出 8 道月牙斩」/「附带感电」

强化后技能图标边框变成银色、金色，强化过的效果在画面上也看得出来（更大、更多、颜色变化）。

- **[MVP]** 所有敌人出招前都有明显预警（抬手动作 + 地面红色区域），给玩家闪避的机会。

- 敌人死亡时：火柴人的肢体散开、被打飞，落地后淡出（见 3.3）。

### Boss
- **[MVP] 哥布林酋长**：巨型绿色火柴人，扛一把大锤。
  - 重锤三连砸：地面三个红圈依次出现
  - 跳起砸地：全屏冲击波，需要跳起来躲
  - 召唤小怪
  - 半血后狂暴：身体变红，出招提速 30%
- 后续：骷髅骑士（冲锋 + 骨刺弹幕）、深渊魔眼（全屏激光，要躲到柱子后面）。
- Boss 血条分多管（×8 这种），被打掉一管时短暂硬直，方便玩家输出。

## 7. 地图结构

- 一张地图 = 4~6 个房间 + 1 个 Boss 房，房间连成网格，右上角小地图显示，Boss 房图标常亮。
- 每个房间 1~3 波怪，清完所有怪后门打开，走到门口进下一间。
- 房间里可以有：可破坏的木箱（掉金币、药）、地刺陷阱、爆炸桶（打一下会炸伤附近敌人）。
- 场景是低多边形的 3D 洞窟：地面、两侧岩壁、前景石柱，远处用剪影面片表现纵深，和火柴人风格统一。运镜转到侧面或背后时，场景也要经得起看。
- **[MVP]** 1 张地图「哥布林洞窟」，4 个普通房 + 1 个 Boss 房，路线固定。
- 后续：第 2、3 张地图（墓地、深渊）；普通 / 冒险 / 地狱三档难度；随机房间排布。

## 8. 局内成长

- 开局：选 1 个觉醒技，带 3 个初始技能（升龙斩、疾风突刺、旋风斩）。
- **[MVP]** 每清完一个房间，从三张卡里选一张：
  - **新技能**：学会一个还没有的技能（技能栏满 6 个后不再出现）
  - **技能强化**：强化一个已有技能（见 5.5）
  - **属性**：暴击率 +15%、MP 回复 +30%、闪避后 2 秒伤害 +30% 等
- **[MVP]** 掉落：金币（算分）、HP 药、MP 药，打怪和木箱随机掉，走过去自动拾取。
- 这套三选一代替 DNF 的装备系统：一局里就有成长感，每局技能组合不同，也不用做背包。

## 9. 局外内容

**已确认只做单局。** 每局从零开始，所有技能、觉醒技、地图一开始就能选，没有解锁和存档。
本机只保存最高分和对应评级（`localStorage`），和星际穿梭一样。不做账号、不做联网排行榜。

## 10. 评分与结算

结算页显示：用时、最大连击、元素组合触发次数、被击次数、击杀数、得分，以及评级。

| 项目 | 计算 |
| --- | --- |
| 基础分 | 击杀分 + 金币 |
| 速度 | 低于目标用时有加成 |
| 技巧 | 最大连击、元素组合次数越多加成越多 |
| 无伤 | 被击次数越少加成越多 |

总分换算成 SSS / SS / S / A / B / C / D。评级用大号字砸到屏幕上，SSS 带金色粒子。首页显示最高评级和最高分。

## 11. 失败与暂停

- HP 归零：可以用一次「复活」（每局 1 次，满血复活，评分降一档），再死就结算。
- 切到后台或手机转成竖屏时自动暂停；右上角有暂停按钮，可以继续、查看技能说明或放弃本局。

## 12. 性能与适配

- 目标：中端安卓机 60 帧，同屏敌人不超过 12 个。
- 粒子、伤害数字、剑气、残影都用对象池复用，不在战斗中频繁创建对象。
- 特效分档：帧率掉到 45 以下时自动关闭 bloom、粒子数量减半（星际穿梭已有类似逻辑，可以参考）。
- 3D 模型都是低面数的基础几何体，所有火柴人共用几何体和材质，只换颜色；同屏 12 个敌人约 150 个肢体网格，手机能承受。
- 几何体、材质、特效贴图在开始页预先创建，第一次放技能时不卡顿。
- 中、重档运镜期间可以短暂提高特效质量，因为这时没有操作压力。
- 支持触屏和键盘；首次进入显示 3 页操作引导，之后可在暂停菜单里重看。

## 13. 第一版（MVP）范围汇总

- 横屏、3D 火柴人（代码生成，不需要素材）、低多边形洞窟场景
- 平时固定斜视角；轻 / 中 / 重三档技能运镜，运镜可跳过、可关闭
- 火柴人：普攻三段、跳斩、闪避
- 8 个普通技能（#1~#8，含火 / 冰 / 雷三种元素）+ 1 个觉醒技（万剑归宗）
- 技能取消连招、元素状态和组合、技能强化
- 4 种普通怪 + 精英怪 + 1 个 Boss（哥布林酋长）
- 1 张地图（5 个房间，路线固定）
- 打击停顿、浮空、伤害数字、震屏、预警红圈、bloom 光效
- 房间三选一（新技能 / 强化 / 属性）、药水掉落
