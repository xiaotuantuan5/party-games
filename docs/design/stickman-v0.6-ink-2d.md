# 火柴人刷图 v0.6：2D 水墨版

本稿把 v0.5 的 3D 画面整体换成 Canvas 2D 程序绘制。关卡、角色、技能、数值、评分、复活规则都不变，只改画面。

## 1. 为什么改成 2D

- 参考图是《忍者必须死》式的平面水墨剪影，2D 更容易画出笔触、留白和纸纹。
- 手机上 2D 的开销更可控：背景预先画好，每帧只画角色和特效。
- 不用任何图片素材，全部由代码绘制。

## 2. 技术做法

| 部分 | 做法 |
| --- | --- |
| 坐标 | 游戏逻辑仍用 x（横向）、y（高度）、z（纵深）。画的时候用斜投影：屏幕 y = y − z × 0.32。 |
| 场景节点 | `Node2D` 继承 three.js 的 `Object3D`，沿用位置、旋转、父子关系。three.js 只当数学库用，不再用 WebGL。 |
| 绘制顺序 | 背景层 → 地面层 → 按纵深排序的角色和道具 → 特效 → 前景层 → 界面。 |
| 背景 | 远景、中景、近景、前景各一张离屏画布，按不同速度视差滚动。地面单独一张。 |
| 光晕 | `shadowBlur` 很贵，每帧最多 24 次（`View.glowBudget`），大面积的形状不加。 |
| 镜头 | 平时横向跟随主角。大招运镜把原来的 3D 机位换算成画面中心和缩放，缩放只取一半变化，最大 1.6 倍，地面始终留在画面里。 |

代码在 `apps/web/src/solo/`：`ink2d.ts`（视图和画笔工具）、`stickmanCamera.ts`、`stickmanFx.ts`、`stickmanRig.ts`、`stickmanTheme.ts`、`stickmanProps.ts`、`stickmanScene.ts`。

## 3. 画风

- 主角：纯黑大头剪影，白色光边，红色飘带（Verlet 模拟），白刃红柄刀。剑客腰间挂刀鞘。元素加成只改光边颜色，身体保持黑色。
- 敌人：灰色武士。哥布林戴头巾持刀，弓手戴斗笠背箭筒，盾兵戴头盔持藤牌，炸弹兵是背火药罐的木偶。
- 首领：体型 1.75 倍，暗红长袍、金冠、大锤。
- 特效：浅色刀光下垫一层淡墨影，墨烟用预先画好的柔边墨团。长枪的拖尾只拖枪头那一段。
